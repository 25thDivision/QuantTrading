## 0. 용어

- **① ~ ⑤**: 보유 기간별 전략 번호
  - ① 하루 (데이트레이딩) - **실전 투입조**
  - ② 2~3일 (단기 스윙) - 페이퍼 전용
  - ③ 일주일 (주간 스윙) - **실전 투입조**
  - ④ 한 달 (월간 리밸런싱) - 페이퍼 전용
  - ⑤ 6개월~ (장기) - 페이퍼 전용
- **오디션**: 동일 조건 백테스트로 후보 전략을 선발하는 절차 (심사 기준 사전 확정)
- **보류 풀**: 실전 명단에서 제외된 전략이 페이퍼 가동 상태로 대기하는 공간. 재오디션 자격 유지
- **인스턴스**: 전략 × 시장 조합 (예: ③-코스피, ③-미국). 검증·강등의 단위
- **파킹**: 대기 현금의 초단기 금리 ETF 임시 예치
- **스윕**: 장 마감 후 당일 분봉을 전 종목 REST 조회로 수집하는 배치 실행
- **소급(backfill)**: 수집 창이 닫힌 과거 거래일의 결손을 일별분봉으로 보충하는 실행
- **장부**: collector_log. 수집 완전성 판정의 유일한 기준 (데이터 부재만으로는 무거래인지 결손인지 알 수 없다)
- **보호됨**: 재실행에서 API 결과가 error였으나 장부 보호(기존 ok/partial 유지) 때문에 기록하지 않은 종목. 실행 결과 집계에만 존재
- **프로브**: DB 기록 없이 API 응답 요약만 출력하는 실행 모드 (`--probe`)
- **run_id**: 한 번의 실행(프로세스)을 식별하는 값. 호출 장부(collector_log·krx_call_log·kis_call_log)와 스냅샷 헤더에 기록해 "어느 실행이 남긴 행인가"를 묶는다
- **사이렌**: #alerts 채널 발송. 정상 완료·예산 도달이 아닌 모든 종료와 부분 실패가 대상 (결정 11 알림 채널, 결정 12 보완 42)

## 1. 프로젝트 운영 원칙 (메타 규칙)

1. **명시 승인 원칙**: 석현님이 명시적으로 결정/허가하지 않은 것은 확정이 아니다. Claude의 제안은 승인 전까지 '제안' 상태.
2. **비관적 가정 원칙**: 백테스트·시뮬레이션에서 모호한 상황(같은 캔들에서 익절·손절 동시 접촉 등)은 항상 불리한 쪽으로 판정한다. 오디션 심사 기준에 명문화.
3. **언어 원칙 (판정의 시효성)**: 전략에 대한 부정 판정은 "현 국면에서의 제외"이며, 보류 풀의 전략은 시장 국면 변화 시 재오디션 대상이 된다. 영구 폐기는 존재하지 않는다 (로직 결함으로 판명된 경우만 예외).
4. **파라미터 원칙**: 모든 수치는 코드에 하드코딩하지 않고 설정 파일 파라미터로 관리한다.
5. **완화 숙려 원칙**: 실전 가동 중 안전장치 수치를 느슨하게 푸는 방향의 변경은 1일 이상 숙려 후 적용. 조이는 방향은 즉시 적용 가능.
6. **승격 예외 규칙**: 기준 미달 상태의 승격은 원칙적으로 불가. 예외 발동 요건 = 석현님 발의 + Claude 명시 동의(만장일치) + 1일 숙려 + 한 줄 로그(어떤 기준을 왜 우회하는지 기록).
7. **검증 순서**: 자체 시뮬 → 한국투자증권 모의투자 API → 소액 실전. 단계 생략 불가.
8. **사실 확인 원칙 (2026-09-22)**: 구현·보고에 쓰는 모든 파일명·경로·사실은 저장소에서 실제 확인한 것만 쓴다. 미확인은 쓰지 않거나 "추정"으로 명시한다. 문서가 언급하는 파일이라도 존재를 확인하기 전에는 존재를 전제하지 않는다. 배경: 결정 8이 예정 도구 scripts/deploy_units.sh를 확정형으로 참조했으나 파일은 미생성 상태였고, Claude Code가 이를 실재하는 것처럼 보고한 사건. 저장소 루트 CLAUDE.md PART C에 동일 규칙 명문화.

## 4. 전략 라인업

### ① 데이트레이딩 (코스피) - 오디션 방식
- 후보 3종을 동일 조건 백테스트로 심사, 심사 기준은 사전 확정:
  - **1-A 변동성 돌파**: 매수가 = 당일 시가 + 전일 변동폭 × k. 장 마감 청산
  - **1-B 시가 범위 돌파 (ORB)**: 개장 첫 N분 박스 상단 돌파 매수, 박스 하단 손절 (N은 백테스트로 탐색)
  - **1-B′ 필터 부착 돌파**: 돌파 신호에 필터(거래량 배수, 갭 방향, 지수 추세 등) 부착. "거래하지 않는 날"을 늘리는 접근
- 심사 기준: 3~5년, 상승/하락/횡보 전 국면 포함(**2026년 7~8월 극변동 국면 필수 포함**), 거래비용(수수료+증권거래세+슬리피지) 차감 후 성과, 비관적 가정 적용
- 전원 기준 미달 시: ① 전체를 보류 풀로 이동 + ③ 증액
- 실행 순서 제약: 장기 분봉 데이터 부재로 **1-A를 일봉 근사로 1차 검증 먼저**, 1-B/1-B′는 분봉 축적 후 (ARCHITECTURE.md 데이터 절 참조)

### ③ 주간 스윙 - 단일 선택
- **2-C 상대 모멘텀 로테이션**을 주 후보로 실전 투입 예정 (2-A 추세 돌파, 2-B 눌림목도 백테스트는 수행)
- **시장 필터 필수 부품**: 지수가 기준(예: 200일 이평) 아래면 신규 진입 중단·현금화. 필터 유/무 백테스트 비교
- 주 1회 리밸런싱, 모멘텀 상위 종목 보유

### ②④⑤ - 페이퍼 전용

## 5. 결정 3 - 안전장치 3층 [관할: 코스피 인스턴스 파라미터]

> 각 층은 서로의 사각지대를 덮는다. 층 1 = 개별 거래의 안전벨트(발동이 일상), 층 2 = 하루의 서킷브레이커(가끔이 정상), 층 3 = 사업 지속 여부의 이사회 소집(발동 자체가 사건).

### 층 1 - 종목당 손절선 (해당 포지션만 즉시 청산, 장중 실시간 감시·집행)
| 대상 | 수치 |
|---|---|
| ① 데이 | **변동성 연동**: 당일 기준 변동폭(전일 ATR 또는 20일 평균 일중 변동폭)의 0.5배, **-3% ~ -6% 클램프**. 1-B 계열은 "박스 하단 vs 연동 손절 중 먼저 닿는 쪽". 오디션에서 고정 % 방식과 비교 검증 |
| ③ 스윙 | **-15%** (재해 손절 - 정상 청산은 리밸런싱). 백테스트에서 -10/-15/-20/없음 비교 |
| 레버리지 슬롯 | **-20 ~ -25%** (ETF 가격 기준, 백테스트로 확정) |

- 한계 명시: 시가 갭은 층 1로 막을 수 없다. 완충 수단은 분산(③ 7종목).
- 즉시 집행이 가능한 구간은 접속매매뿐 (결정 9). 마감 단일가·VI 발동 중의 처리 규칙은 risk 모듈 설계 시 확정 (11절)

### 층 2 - 일일 계좌 kill switch (계좌 통합 기준, 2단계)
- **-3% 소프트 정지**: 신규 진입 전면 금지, 보유는 층 1에 위임
- **-5% 하드 정지**: 보유 전량 청산 + 당일 거래 종료 + 디스코드 긴급 알림
- 다음 거래일 자동 재개
- 실전 2개월 무사고 후 **-4% / -6%로 완화** (완화 숙려 원칙 적용)

### 층 3 - 누적 드로다운 정지선 (고점 대비, 이중 구조)
- **전략별 -15% + 계좌 전체 -18%**
- 발동 시: 해당 범위 전략 정지 + 디스코드 알림 + **자동 재개 없음** - 석현님의 원인 리뷰와 명시적 재가동 명령 필요
- 수치는 출발값: **오디션 백테스트 MDD × 1.2~1.5로 재설정하는 것을 전제**
- 발동 후 판결 선택지: 수정 후 재투입 / 재오디션 / 보류 풀 이동

## 6. 결정 4 - 배분·포지션 크기

- **포지션 크기 = 고정 리스크 방식**: 포지션 금액 = (계좌 × 리스크%) ÷ |손절폭|
  - ①: 리스크 **1%** → 변동성 연동 손절과 결합해 포지션 83~167만 동적. **동시 1포지션**
  - ③: 리스크 **1.5%** → 50만/포지션 × **7종목** (350만 기준). 백테스트에서 종목 수·리스크 민감도 비교
  - 공식은 시장 공통, 산출값은 시장별 (미국 인스턴스는 미국 손절폭으로 재산출)
- **주당 가격 상한**: ① 20만 / ③ 16만 (최소 3~4주 확보 기준)
  - **소수점 거래 미지원 확정 (2026-09-14)**: 공식 약관("소수점거래 대상은 미국주식에 한함")과 API 카탈로그 전수 확인으로 국내주식 소수점 주문 미지원 확인 → 주당 상한 유지, **삼성전자·SK하이닉스 등 초고가주는 반도체·지수 ETF 대체 슬롯으로 노출 확정** (③ 보통주 원칙의 명시적 예외. 화이트리스트·최대 비중 등 슬롯 세부는 미확정)
- **레버리지 슬롯**: ③ 내 최대 50%(175만). 모멘텀 순위 경쟁에서 분리된 별도 슬롯, 시장 필터 통과 시에만 진입, 리스크 역산 적용
- **파킹**: ③ 대기 자금(빈 슬롯·시장 필터 발동분)은 CD금리/KOFR형 ETF **화이트리스트(1~2종 지정)**에 자동 파킹. 파킹 포지션은 종목 수·상한·리스크 계산에서 제외. **① 자금은 파킹 없이 현금 유지** (회전 빈도상 실익 없음)
- 무리한 슬롯 채우기 금지: 조건 충족 종목이 부족하면 남는 자금은 파킹/현금
- 미체결 주문 N분 후 자동 취소, 부분 체결 잔량 처리 → 구현 단계에서 확정

## 7. 결정 5 - 코스피 유니버스

### 공통 제외 (하드)
- 관리종목, 거래정지, 투자위험(최고 단계) - 자동매매가 대응 불가능한 상폐·정지 경로 차단 목적
- 투자경고(중간 단계)는 **허용하되 신규 진입 시 포지션 절반**
- 참고: 시총 상위 100 종목은 제도상 초장기상승형 투자경고 지정에서 제외되어 있음 (삼전·하이닉스가 유니버스에서 빠질 일 없음)

### 신규 상장주
- 상장 1주 후부터 ① 편입 가능 (지표는 가용 일수로 계산, 최소 5거래일), 3개월 후부터 ③ 편입 가능
- 신규주 거래는 포지션 절반 + 별도 성과 집계로 시작

### ① 유니버스
- 보통주 + **ETF 포함** (ETF는 매도 시 증권거래세 면제 - 데이트레이딩 비용 이점. 레버리지 계열은 규제 제한사항 확인 후 반영 - 석현님 확인 예정)
- 일평균 거래대금(20일) **100억 이상**, 20일 평균 일중 변동폭 **2.5% 이상**
- 시총 하한 5천억, **상한 없음** (2026년 국면에서 초대형주도 변동성 필터 통과 확인)
- 갱신: 매일 장 전

### ③ 유니버스
- **보통주만** (레버리지는 별도 슬롯로만, 일반 ETF 미포함 - 대체 슬롯 예외는 결정 4 참조)
- 일평균 거래대금(20일) **10억 이상**, 시총 하한 3천억, 상한 없음
- 갱신: 리밸런싱 주기와 동기 (매주)

### 공통 안전장치
- 보유 중 유니버스 탈락 시 강제 청산하지 않음 - 유니버스는 신규 진입만 통제

## 8. 결정 6 - 실전 전환 기준 (모의 → 실전)

> 모의투자의 목적은 수익 확인이 아니라 **시스템이 설계대로 움직이는지** 확인. 수익률은 통과 조건이 아니다.

- **기간 밴드**: ① 4~8주 / ③ 6~10주. 하한 전 승격 불가. 상한 도달 시 **강제 리뷰**: 원인 특정·수정 시 2주 연장 1회 / 원인 불명·반복 시 모의 중단 + 근본 재설계
- **통과 조건 - 시스템 하드 조건 (전부 충족)**:
  - 미처리 예외·크래시 0건 (systemd 자동 재시작된 크래시도 실격 사유)
  - 주문 사고 0건 (의도치 않은 주문, 중복, 수량 오류, 유령 포지션)
  - 층 1 실제 발동·정상 집행 실증. 층 2는 자연 발동 없으면 강제 트리거 테스트로 검증
  - 디스코드 알림 도달, 원격 정지·재개 명령, 재시작 후 계좌 대사 성공 실증
- **통과 조건 - 정합성**:
  - 신호 일치율 **95% 이상** (동일 기간 백테스트 재현 대비). 미달 = 실격이 아니라 **환경 조사 트리거**
  - 미규명 불일치 존재 시 승격 보류 (규명될 때까지)
  - 체결가 괴리 기준: 구조만 확정("실측 괴리 ≤ 백테스트 슬리피지 가정"), 수치는 오디션 설계에 위임
  - 손익 괴리: 참고 지표로 기록만, 합격 조건 아님
- **투입액 사다리**: ③ 150만 → 4주 무사고 → 350만 / ① 50만 → 4주 무사고 → 150만
- **강등**: 실전에서 시스템 하드 조건 위반 발생 시 해당 인스턴스 자동 모의 강등 + 수정 + 모의 2주 재검증 후 복귀. 석현님 수동 강등권 상시 유효

## 9. 결정 7 - ③ 미국 확장 (독립 검증 체제)

- **독립 검증 원칙**: 미국 ③은 코스피 ③의 이관이 아니라 **별도 인스턴스**. 미국 데이터로 독자 백테스트, 독자 파라미터, 결정 6의 검증 사다리를 독자적으로 통과해야 실전 자금 투입 가능. 코스피 트랙레코드가 면제하는 것은 봇 시스템 신뢰뿐, 전략 검증은 면제 없음
- 근거: 코스피(2026 극변동 국면)와 미국은 시장 성격이 달라 파라미터·성립 여부를 각자 검증해야 함. 파라미터 재튜닝은 경고가 아니라 정상 절차
- **자금 배분**: 어느 한 시장이라도 검증을 통과하는 시점에 재논의하여 결정 (시드 증액 가능성 포함). 그 전까지 확정된 것은 "미국 검증 통과 전 미국 실돈 투입 불가"라는 관문뿐
- **역방향 규칙**: 강등은 인스턴스 단위 (미국 사고 시 미국만 강등, 코스피 지속). 단 원인이 공통 코드로 판명되면 양쪽 강등. 강등 인스턴스는 보류 풀에서 페이퍼 가동. **강등된 쪽 자금은 다른 인스턴스로 자동 이동하지 않고 파킹 대기** - 재배치는 원인 리뷰 후 석현님 수동 결정
- 미국 사전 검증 항목(병렬 진행 가능): 미국 유니버스 구성(범위 미정), 데이터 파이프라인, 미국 독자 백테스트, 한국투자증권 미국 API·모의 지원 범위 검증, 운영 차이 반영(장 시간·서머타임·환전·결제), 거래 비용 실측

- **동시 실행 방지** (2026-09-30 확정, 2026-09-30 구현 - 커밋 c3048ab, `quant_trading/broker/lock.py`): 어댑터의 유량 리미터는 프로세스 안에서만 동작하므로, 같은 머신에서 같은 env(실전/모의) 키를 쓰는 수집 프로세스가 겹치면 합산이 한도를 넘어 EGW00201 재시도·소진이 발생한다(2026-09-28 소급 2건 동시 실행으로 실증). 대응: env별 파일 잠금(`data/locks/kis_<env>.lock`, fcntl.flock). 잠금을 못 잡으면 기본은 앞 프로세스 종료까지 대기(커널 대기, CPU 미사용, "대기 중" 로그 필수), `--no-wait`이면 즉시 종료(별도 종료코드). 돌고 있는 프로세스를 죽이는 동작은 없다. 구현 시점의 재시도 주기는 로그 주기와 같은 60초(config `broker.lock.wait_log_sec`)이며, 재시도 5초·로그 60초로 분리하는 변경은 지시 문안 2에 포함 예정. 타이머 스윕이 수동 소급 뒤에서 대기하는 시간은 collector.service의 TimeoutStartSec 6h 안에 포함되나 실전 키 소급 최대 약 21분이라 감수(2026-10-01 현행 유지). 스윕 샤딩 등 병렬 실행을 도입할 때 잠금 단위를 재설계한다
