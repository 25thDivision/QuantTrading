## 공통 호출 규약 (명세서 + 공식 FAQ)
- 엔드포인트: `https://data-dbg.krx.co.kr/svc/apis/<분류>/<API ID>` (명세서 표기). 분류: 주식 `sto`, 지수 `idx`, 증권상품 `etp`
- 요청: `basDd` (기준일자, `YYYYMMDD`) 하나. 호출 1회 = 기준일 1일 = 해당 시장 전 종목
- 인증: 요청 헤더 `AUTH_KEY: <인증키>`. 인증키는 .env의 `KRX_AUTH_KEY`로만 관리 (CLAUDE.md PART E)
- 응답: `{"OutBlock_1": [ {...}, ... ]}`. 값은 전부 문자열(명세서 Type 전부 string)
- 휴장일·갱신 전 당일 조회: 빈 배열 (오류 아님)
- 한도: 인증키당 일일 10,000회. 과도 접속은 IP 차단 사유(기준 수치 없음)
- 갱신: 전일분이 익영업일 08:00. 당일·실시간 데이터 없음

## 데이터 정의 (공식 FAQ)
- basDd의 종목 기준 = 해당 거래일 장 종료 시점에 그 시장에 상장되어 있던 종목. 이후 상장폐지 종목도 포함, 거래정지 종목도 상장 상태면 포함
- 시가·고가·저가·종가 = KRX 정규시장 형성 가격. 거래량·거래대금 = 시간외(장개시전 시간외종가·시간외대량) + 애프터마켓(2026-09-14 이후) 포함 KRX 전체
- 정규시장 무체결일: 시가·고가·저가 0. 종가는 기세가격이 반영될 수 있고 거래정지 종목은 직전가
- 비수정 원가격. 액면분할·병합·권리락 소급 조정 없음
- 단위: 가격·거래대금 원, 거래량 주
